Compress a PDF Online

Choose an approximate reduction percentage or enter a target KB size. The tool rebuilds PDF pages as images, so inspect quality and text behavior before sharing.

🔒 Selected files are processed in your browser. File contents are not sent to a ResizeTool upload endpoint.

Open the compress a pdf online tool

The tool opens on the main ResizeTool page. Choose a file there to begin.

How to compress a pdf online

  1. Select a PDF file.
  2. Enter a reduction percentage or target size in KB.
  3. Compress and download the result. Check page count, small text, and file size against the original.

Questions and answers

Will the compressed PDF remain searchable?

The current compressor rebuilds pages as images, so searchable text and some PDF features are not preserved.

Will it always make the PDF smaller?

Already optimized or mostly vector PDFs may not shrink much. The tool reports if it cannot make a smaller copy at acceptable clarity.

Are my PDF pages uploaded?

The selected PDF is processed in your browser and its contents are not sent to a ResizeTool upload endpoint.
