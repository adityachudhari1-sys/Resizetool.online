Who we are

About ResizeTool

ResizeTool is a browser-based toolkit for preparing images and documents for everyday forms, websites, and sharing.

What the site provides

The main workspace brings together image resizing, target-size compression, cropping, format conversion, photo adjustments, and selected PDF workflows. The additional tools page includes ratio and print-size calculators, image details and color sampling, and text watermarking.

These utilities are designed to make common file-preparation steps easier to understand. Output can differ based on the source file, browser, device memory, and destination requirements, so users should review exported files before submitting or sharing them.

How browser processing works

Image utilities use browser features such as Canvas and local file access. The file tools on this site process selected files in the browser tab and provide downloads from that session. The site also uses third-party analytics and advertising services; see the Privacy Policy for more information.

Corrections and feedback

For a bug report, correction, accessibility issue, or feature suggestion, contact resizetool@yahoo.com. Include the page name and browser/device details if they help explain the issue. Do not email sensitive documents or photos.
