Compress an Image Online

Use the target size field when an upload has a KB limit, or adjust quality when you want to balance file size and image detail.

🔒 Selected files are processed in your browser. File contents are not sent to a ResizeTool upload endpoint.

Open the compress an image online tool

The tool opens on the main ResizeTool page. Choose a file there to begin.

How to compress an image online

  1. Choose an image from your device.
  2. Enter a target size in KB, or adjust the quality slider.
  3. Compress, download the JPEG, and check the resulting file size and appearance.

Questions and answers

Can I set a target file size?

Yes. Enter a target in KB. The browser tool adjusts JPEG quality and reports when the target cannot be reached.

Does compression change image dimensions?

The target-size control changes JPEG quality; it does not reduce pixel dimensions. Use the image resizer first if dimensions also need to change.

Are my images uploaded?

The selected image is processed in your browser. Its file contents are not sent to a ResizeTool upload endpoint.
