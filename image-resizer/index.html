Resize an Image to Exact Pixels

Set a width and height in pixels, or enter a percentage of the original. Keep the aspect ratio on to avoid stretching the photo.

🔒 Selected files are processed in your browser. File contents are not sent to a ResizeTool upload endpoint.

Open the resize an image to exact pixels tool

The tool opens on the main ResizeTool page. Choose a file there to begin.

How to resize an image to exact pixels

  1. Choose an image.
  2. Enter the required width and height, or adjust the percentage fields.
  3. Keep aspect ratio selected when the original proportions should stay the same, then download the JPEG.

Questions and answers

Does resizing reduce file size?

It often does because fewer pixels need to be stored, but the final size also depends on image content and JPEG encoding.

Can I keep the original shape?

Yes. Keep the aspect ratio option selected while changing width or height.

What format does the resizer download?

The current resizer exports a JPEG. Use the format converter if the receiving service asks for PNG or WebP.
