Word / PowerPoint / Excel → PDF

Modern .docx, .xlsx and .pptx files are supported. Older .doc, .ppt and .xls files need a server converter. The browser converter extracts text and creates a simplified layout; embedded pictures, charts and original formatting may not carry over.

Compress PDF

Compress one PDF in your browser. Pages start at about 144 DPI and resolution steps down only as needed, which keeps text sharper than aggressive low-resolution compression. The browser rebuilds pages as images, so searchable text and some PDF features are not preserved. Already optimized or mostly vector PDFs may not shrink much.

Enter a percentage for automatic compression, or enter a target size in KB. If both are entered, the target KB is used.

Practical guides for image and document tasks

These notes describe the controls available on this page, including where conversion can change a file. Start with the current requirements from the website, school, employer, or agency that will receive your file.

Image dimensions

Choose pixel dimensions before resizing

Pixel dimensions are the number of pixels across and down an image. They are different from file size in KB. If a form asks for a width and height, enter those exact pixel values in Resize Image and keep the aspect ratio option selected when the original shape should stay unchanged.

Changing the shape can stretch faces or objects. If a site requires a different shape, crop the image first and then resize it. Enlarging a small image does not restore detail that was not in the original, so review the result at full size before using it.

The Resize Image tool downloads a JPEG. If the destination requires another format, use Convert Image and choose the format it accepts.

File size

Reduce an image to a size limit

A file-size limit and a pixel-dimension requirement are separate. Resizing changes the number of pixels. Compression changes how the image data is stored. For a strict KB limit, first check the required dimensions, then use Compress Image with a target size or the quality control.

The target-size option adjusts JPEG quality; it does not shrink the image dimensions. It tries to find the highest quality that fits the target. If even the lowest quality is still too large, the tool reports that the target was not reached. Leave a little room below a strict upload limit and check the downloaded file.

Image formats

Pick a format the recipient accepts

JPEG is commonly used for photographs and can produce smaller files, but each JPEG save can discard image detail. PNG keeps image data losslessly and supports transparency, which is useful for logos and graphics but can make files larger. WebP can be compact, but some upload forms do not accept it.

Convert Image can export JPEG, PNG, or WebP. Check the receiving service's allowed formats before converting. Keep your original file so you can make a different version without repeatedly recompressing an already compressed image.

Crop and ID photo

Prepare a photo for an application

Crop Image lets you choose a free crop or a common aspect ratio. Its manual X, Y, width, and height fields use percentages of the original image. Crop before resizing when the required shape differs from your source photo.

The ID Photo tool changes pixel dimensions only. Before using a preset, check the receiving organization's rules for accepted format, maximum file size, background, lighting, face position, and photo age. The tool does not inspect or certify those requirements.

Images to PDF

Prepare an image-based PDF

Choose the images you want to include, then select A4 or Letter paper and portrait or landscape orientation. Review the selected files and their order before creating the PDF. Large photos can make a large PDF, so use the smallest dimensions that still meet the recipient's requirements.

These pages are built from the selected images. Text inside a photo remains part of the picture; it is not converted into selectable PDF text.

PDF review

Check the compressed PDF before sharing

Open the original and the compressed copy side by side. Check page count, small labels, photographs, and fine lines at normal reading size and at a closer zoom. A smaller file is only useful if the important details remain readable.

Keep the original PDF. If the compressed copy looks too soft, use a smaller reduction or share the original when the recipient's file-size limit allows it.

Document conversion

Prepare files before converting

For a Word document, use clear section headings and remove blank paragraphs before converting. For a spreadsheet, check the print area and page orientation in the source application first. These choices affect what appears on the PDF pages.

After conversion, inspect page breaks, tables, charts, formulas, and text that may run off the page. For Word to PowerPoint, use a heading only where you want a slide title, then review each slide for overflow before presenting.
