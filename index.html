Word / PowerPoint / Excel → PDF

Modern .docx, .xlsx and .pptx files are converted in your browser. No upload is required. Older .doc/.xls files need a server converter.

Compress PDF

Compress one PDF directly in your browser. This works especially well for scanned/photo PDFs. Text/vector PDFs may have limited size reduction. The browser version rebuilds pages as images, so searchable text and some original PDF features may not be preserved.

Enter a percentage for automatic compression, or enter a target size in KB. If both are entered, the target KB is used.

PDF → PowerPoint

Convert each PDF page into a PowerPoint slide. The slide preserves the page appearance as an image, making this suitable for scanned documents and PDFs with mixed content. Each PDF page is placed on a PowerPoint slide as an image, so the slide appearance is preserved but the original PDF text is not converted into editable PowerPoint text.

Word → PowerPoint

Convert a .docx Word document into a PowerPoint presentation. Headings become slide titles and paragraphs become slide content.

Frequently Asked Questions

Are my images uploaded to a server?

Browser-based image tools on this page process selected images locally in the browser.

Can I resize an image to exact pixels?

Yes. Enter the required width and height in pixels and use the Resize Image tool.

Can I compress an image to a target KB size?

Yes. Enter a target size in KB and ResizeTool will try to produce a JPEG close to that size.

Can I make an image into a PDF?

Yes. Select multiple images, choose A4 or Letter and choose portrait or landscape orientation.
