Free browser utilities

More image tools

Four small utilities for checking image dimensions, planning print size, making a simple color palette, and adding a text watermark. The file tools run in this tab; images are not uploaded by these controls.

Aspect ratio calculator

Enter a width and height to reduce them to their simplest ratio and calculate a matching dimension.

Print size calculator

Estimate print dimensions from pixel dimensions and a chosen print resolution.

Image details and color palette

Choose an image to see its dimensions, file size, format, aspect ratio, and a sampled palette. Processing happens locally in your browser.

Add a text watermark

Preview and download a JPEG copy with a simple text mark. The original file is not modified.

Using these tools

The ratio calculator simplifies dimensions using their greatest common divisor. The print calculator converts pixels to inches and centimetres using the entered DPI; it is an estimate and does not change the image file’s embedded metadata. The palette samples a scaled copy of the selected image, so the displayed colors are representative rather than a complete color profile. Watermarking exports a JPEG, which flattens transparency and may change quality. Keep a copy of the original if you need the original format or transparency.
