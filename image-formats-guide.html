Image basics

Choosing JPG, PNG, or WebP

No format is best for every image. Choose based on what it contains, whether transparency matters, and what the receiving site accepts.

JPEG for photographs

JPEG is widely supported and efficient for continuous-tone images such as photos. It uses lossy compression: saving repeatedly can add artifacts, especially around text, sharp edges, and fine patterns. Keep a high-quality original and export from that source when possible.

PNG for transparency and crisp graphics

PNG preserves sharp boundaries and supports transparency without lossy compression. It is a strong choice for logos, interface graphics, screenshots with text, and signatures. A complex photograph may take more storage as PNG than as a lossy format.

WebP for compatible web delivery

WebP supports lossy and lossless compression and can keep web images compact. Before converting, confirm that the destination or older application supports WebP. A smaller file is useful only if the recipient can open it.

Transparency and conversion

JPEG does not preserve transparency. Transparent areas may be filled with a solid background when converted to JPEG. Inspect the output background and edges after conversion, especially around cutouts and logos.

Keep an original copy

Compression and format conversion can discard information. Retain the source file if you may need to edit it later, and compare the exported image at actual display size rather than relying only on the file extension.
