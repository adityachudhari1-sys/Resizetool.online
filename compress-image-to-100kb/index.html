Compress an Image to 100KB

Enter 100 in the target size field to ask the browser compressor to make a JPEG close to that size. The result depends on the source image and its dimensions.

🔒 Selected files are processed in your browser. File contents are not sent to a ResizeTool upload endpoint.

Open the compress an image to 100kb tool

The tool opens on the main ResizeTool page. Choose a file there to begin.

How to compress an image to 100kb

  1. Check whether the recipient means KB (not pixels) and whether it sets a strict maximum.
  2. Choose the image and set the target to 100 KB.
  3. Download the result, then check the actual file size and readability. Leave a margin if the limit is strict.

Questions and answers

Will every image reach exactly 100KB?

No. The compressor searches JPEG quality settings and aims for the target; some images cannot reach it without excessive quality loss.

Will the image dimensions change?

No. The target-size control changes JPEG quality. Resize the image first only if the recipient allows different pixel dimensions.

Why leave a little room below the limit?

Upload systems can enforce a strict maximum, and rounded size displays may differ. Check the downloaded file rather than relying on the target entry alone.
