Convert Images to PDF

Combine selected images into a PDF page sequence. Text within a photo stays part of that image and is not converted into selectable text.

🔒 Selected files are processed in your browser. File contents are not sent to a ResizeTool upload endpoint.

Open the convert images to pdf tool

The tool opens on the main ResizeTool page. Choose a file there to begin.

How to convert images to pdf

  1. Select the images you want in the PDF and review their order.
  2. Choose A4 or Letter paper and portrait or landscape orientation.
  3. Create and download the PDF, then review page order and readability.

Questions and answers

Can I make a searchable PDF from photos?

This tool places images on PDF pages. Text in those images is not converted into selectable text.

Which paper sizes are available?

The current tool offers A4 and Letter with portrait or landscape orientation.

Can I reduce a large image PDF afterward?

Yes. Use the PDF compressor, then check image clarity because compression may reduce page detail.
